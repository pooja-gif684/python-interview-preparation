89. What is the difference between iteration and recursion?
   - Answer: Iteration uses loops to repeat actions, while recursion calls a function repeatedly until a base condition is met.

     ```python
     for i in range(3):
     ```

92. What is the purpose of the __iter__ and __next__ methods?
   - Answer: They are used to create iterator objects that can be iterated over with for loops.
   - Example:
     ```python
     class Counter:
         def __iter__(self):
             self.n = 0
             return self
         def __next__(self):
             if self.n < 3:
                 self.n += 1
                 return self.n
             raise StopIteration
     for x in Counter():
         print(x)
     ```
